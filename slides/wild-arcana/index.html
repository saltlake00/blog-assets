센트럴파크를 실제 GIS 데이터로 1:1로 옮겼다. 라이다 높이, 뉴욕시 건물 윤곽, OSM 길·물·숲 세 가지를 파이썬으로 필드 좌표에 맞춰 가공하고, 같은 가공 결과로 지형·건물·지도·미니맵을 모두 만들었다. 처음엔 1km 타일 하나였고 나중에 공원 전체 4km로 넓혔다.

02 · Claude로 만든 것

GIS 환경 구성 단계

  • 데이터 DEM·건물·OSM 3종 합성, 원 타일 1024m 건물 658동 (주황 사각: 첫 플레이 구역)
  • 지형 높이맵 + 스플랫 4층, 타일 이음새 높이 차 평균 1~2mm
  • 건물 윤곽·높이 돌출, 원경은 256m 격자로 합친 메시
  • 지도 같은 GIS 데이터로 PNG 굽기, 북쪽 위
  • 미니맵 같은 지도 텍스처, 반경 100m, 북쪽 고정 (왼쪽 게임 화면, 오른쪽 같은 자리 위에서)
→ → → → →
칩을 차례로 눌러 데이터에서 미니맵까지 보여 준다. 지형은 나무 없이 높이·길·물만 올린 에디터 화면, 건물은 외곽선을 높이만큼 올린 첫 판, 필드는 식생까지 올린 화면. 미니맵은 왼쪽이 게임 미니맵, 오른쪽이 같은 자리를 위에서 본 장면이다.
